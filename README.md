# Homeschooling App

A mobile application developed in Java (Android Studio) that connects parents seeking home tutors with qualified tutors nearby.

## Features

- Parent Registration & Login
- Tutor Registration & Login
- Role-Based Authentication
- Tutor Profile Management
- Parent Profile Management
- Tuition Requirement Posting
- Tutor Search & Matching
- Firebase Authentication
- Firebase Realtime Database
- Splash Screen
- Tuition Listing Module

## Tech Stack

- Java
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Material Design Components

## Future Enhancements

- In-App Chat
- Attendance Tracking
- Escrow Payment Simulation
- Ratings & Reviews
- Google Maps Integration
- Admin Dashboard
